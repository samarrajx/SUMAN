## Steps

1. Add your photos to `assets/images/` with EXACT filenames
2. Add `lofi.mp3` to `assets/music/`
3. Compress all images at squoosh.app (WebP, max 200KB each)
4. Deploy to GitHub Pages:

```
git init
git add .
git commit -m "Suman ka surprise 🌸"
git branch -M main
git remote add origin https://github.com/[username]/suman-birthday.git
git push -u origin main
```

5. Repo Settings → Pages → Branch: main → / (root) → Save
6. Link: https://[username].github.io/suman-birthday
7. WhatsApp pe bhejo 🎉
